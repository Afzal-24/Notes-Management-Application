# 📝 Notes Management Application

A full-stack **Notes Management Application** built using **React.js, TypeScript, Node.js, Express.js, and MongoDB** with a clean architecture, responsive UI, JWT authentication, and Kanban drag-and-drop functionality.

---

## 🚀 Features

### ✅ Frontend Features
- Modern & Responsive UI
- Notes List View
- Kanban Board View
- Drag & Drop Support
- Add / Edit / Delete Notes
- Authentication System
- Redux Toolkit State Management
- Protected Routes
- API IntegratioN

### ✅ Backend Features
- REST APIs with Express.js
- JWT Authentication
- CRUD Operations
- MongoDB Database Integration
- Middleware-based Route Protection
- Clean MVC Architecture

---

# ⚙️ Installation Guide

## Clone Repository

```bash
git clone https://github.com/Afzal-24/Notes-Management-Application.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside backend folder:

```env
PORT=000
MONGO_URI=your_mongodb_connection
SECRET_KEY=your_secret_key
```
